# Agilex 5 FPGA E-Series 065A Premium Development Kit — HPS Enablement

Platform folder `dk-a5e065ab32aea-enablement` contains designs for the Agilex 5 FPGA
E-Series 065A Premium Development Kit DK-A5E065AB32AEA with the HPS Enablement Expansion
Board (OOBE daughter card).

Refer to the [Agilex 5 E-Series Premium Development Kit Baseline System Example Design](https://altera-fpga.github.io/latest/embedded-designs/agilex-5/e-series/premium-065a/gsrd/ug-gsrd-agx5e-premium-065a/) for Baseline System Example Design context.
